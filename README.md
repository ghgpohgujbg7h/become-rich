# BECOME RICH — 3D Life Simulator

A browser-based life simulation prototype. Start as a baby, grow through kindergarten and school, study practical real-world lessons, complete three tests per grade, attend college, choose a career, earn money, and decide how to spend or save it.

## Run it
Open [the game](https://ghgpohgujbg7h.github.io/become-rich/) after enabling GitHub Pages for this repository (Settings → Pages → Deploy from branch → main → /(root)). You can also open `index.html` locally while connected to the internet (Three.js is loaded from a CDN).

## Features
- 3D low-poly world built with Three.js
- Life stages: baby, kindergarten, grades 1–12, college, work and adult choices
- Short practical lessons and three tests per grade
- Career choices, salaries, purchases and local save progress
